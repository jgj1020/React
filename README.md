# ⚛️ 나의 첫 리액트(React) 학습 노트

> Vite를 이용해 만든 리액트 공부방입니다. 배운 내용을 여기에 차곡차곡 정리합니다.

---

## 1. 초기 세팅 명령어

* **`npm create vite@latest react-study -- --template react`**
  * 마트에서 리액트 레고 상자(폴더와 설계도 파일)를 사서 내 컴퓨터에 가져오는 것.
* **`cd react-study`**
  * 조립을 시작하기 위해 방금 가져온 레고 상자 안으로 내가 직접 들어가는 것.
* **`npm install`**
  * 설계도(`package.json`)를 보고 조립에 필요한 진짜 레고 블록 부품들(`node_modules`)을 상자 안에 와르르 쏟아붓는 것.
* **`npm run dev`**
  * 내 컴퓨터에 임시 서버를 켜서, 내가 만든 리액트 화면을 웹 브라우저로 실시간 확인하는 것.

---

## 💡 2. 리액트 핵심 개념 (한 줄 요약)

### 컴포넌트 (Component)
* 웹사이트를 이루는 **'레고 블록(조립식 부품)'**으로, 버튼이나 메뉴바처럼 따로 만들어 재사용하는 코드 뭉치.

### 상태 (State)
* 웹 화면에서 숫자가 올라가거나 글자가 바뀌는 것처럼, **'실시간으로 변하는 화면 데이터'**를 담는 바구니.

## 3. 깃허브 올리는 방법

```bash
# 1. 깃 관리 시작하기
git init

# 2. 올릴 파일들 바구니에 전부 담기 (끝에 점 '.' 꼭 찍기)
git add .

# 3. 이번 업로드에 이름표(메모) 달기
git commit -m "들어갈 내용 수정내용"

# 4. 내 컴퓨터와 방금 만든 깃허브 주소 연결하기
git remote add origin 주소

# 5. 연결된 깃허브로 파일 진짜로 보내기
git push -u origin main
