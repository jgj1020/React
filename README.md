| :--- | :--- |

## 🛠️ 1. 초기 세팅 명령어

* **`npm create vite@latest react-study -- --template react`**
  * 마트에서 리액트 레고 상자(폴더와 설계도 파일)를 사서 내 컴퓨터에 가져오는 것.
* **`cd react-study`**
  * 조립을 시작하기 위해 방금 가져온 레고 상자 안으로 내가 직접 들어가는 것.
* **`npm install`**
  * 설계도(`package.json`)를 보고 조립에 필요한 진짜 레고 블록 부품들(`node_modules`)을 상자 안에 와르르 쏟아붓는 것.
* **`npm run dev`**
  * 내 컴퓨터에 임시 서버를 켜서, 내가 만든 리액트 화면을 웹 브라우저로 실시간 확인하는 것.

## 💡 2. 리액트 핵심 개념 및 문법 (한 줄 요약)

| 용어/문법 | 한 줄 정의 | 이해하기 쉬운 비유 🧱 |
| :--- | :--- | :--- |
| **컴포넌트** | 웹사이트를 이루는 조립식 부품 코드 뭉치 | 버튼이나 메뉴바 같은 **'레고 블록'** |
| **상태 (State)** | 실시간으로 변하는 화면 데이터를 담는 곳 | 전광판에 표시될 **'실시간 데이터 바구니'** |
| **useState** | 실시간으로 화면을 바꾸고 싶을 때 쓰는 도구 | 변수 상자(상태)를 만드는 **'마법의 도구 세트'** |
| **'react'** | 리액트 핵심 기능이 들어있는 라이브러리 본체 | 마트에 있는 거대한 **'레고 본사 창고'** |
| **function** | 특정 기능을 수행하는 블록을 만드는 명령어 | 원하는 부품을 만들기 위한 **'첫 신호탄 (붕어빵 틀)'** |
| **App** | 내 웹사이트 전체를 대표하는 대장 이름 | 이 웹사이트 전체 판을 짜는 **'대장 레고 블록'** |
| **const** | 이름표를 앞으로 절대 바꾸지 못하게 고정하는 명령어 | 이름이 헷갈려 바뀌지 않도록 단단히 고정하는 **'방어벽'** |
| **`{ }` (중괄호)** | 진짜 변수나 디자인 상자를 화면에 넣는 문법 | 자바스크립트 마법을 실행하는 **'실행 스위치'** |
| **`{{ }}` (이중중괄호)** | 리액트 태그 안에 디자인 스타일을 직접 넣는 문법 | 스위치(`{`)를 켜고 디자인 묶음 상자(`{}`)를 통째로 넣은 것 |
| **textAlign** | 글자나 정렬 대상의 가로 위치를 지정하는 속성 | 글자와 버튼들을 화면 정가운데로 보내는 **'가운데 정렬'** |
| **marginTop** | 바깥쪽 울타리 천장과의 간격을 조절하는 속성 | 웹사이트 맨 꼭대기 천장으로부터 아래로 공간을 띄우는 **'머리 여백'** |
| **padding** | 내용물과 테두리 사이의 공간을 조절하는 속성 | 보이지 않는 쿠션을 넣어 버튼 덩치를 통통하게 키우는 **'안쪽 여백'** |
| **fontSize** | 화면에 보여지는 글자(텍스트)의 크기를 지정하는 속성 | 글씨 크기를 시원시원하게 조절하는 **'폰트 크기 변경'** |
