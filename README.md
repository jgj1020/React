## 💡 2. 리액트 핵심 개념 및 문법 (한 줄 요약)

| 용어/문법 | 한 줄 정의 |
| :--- | :--- |
| **textAlign: 'center'** | 상자 안의 모든 글자와 버튼들을 화면 정가운데로 모아주는 **'가운데 정렬'** 속성 |
| **marginTop: '30px'** | 웹 브라우저 맨 꼭대기 천장으로부터 아래로 30픽셀만큼 공간을 띄우는 **'바깥쪽 위 여백'** 속성 |
| **fontFamily: 'sans-serif'** | 딱딱한 붓글씨체를 스마트폰 앱처럼 깔끔하고 모던한 고딕체로 바꿔주는 **'글씨체 변경'** 속성 |
| **marginBottom: '30px'** | 밑에 있는 다른 카드나 버튼들이 내 몸통에 바짝 붙지 못하도록 아래쪽으로 30픽셀만큼 빈 공간을 밀어내어 확보하는 **'바깥쪽 아래 여백'** 속성 |
